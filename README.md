# Project 1: Sales Performance Dashboard Analysis

## 🎯 Objective
Developed an interactive Business Intelligence (BI) dashboard to transform raw transactional data into actionable business insights. This dashboard tracks key sales metrics, evaluates regional performance, and analyzes monthly trends to support data-driven decision-making.

## 🛠️ Tech Stack & Skills Learned
- **Tool:** Power BI Desktop
- **Data Transformation:** Power Query (Data cleaning, type casting)
- **Data Modeling:** Built-in semantic financial modeling
- **Visuals Used:** KPI Cards, Line Charts (Time-Series Hierarchy), Clustered Bar Charts, Interactive Slicers
- **Key Concepts:** Drill-down analysis, dashboard layout design, user interactivity

## 📊 Dashboard Features
1. **Executive Summary KPIs:** Real-time visibility into Total Revenue ($118.73M) and Total Profit ($16.89M).
2. **Time-Period Analysis:** A detailed Monthly Sales Trend chart that captures seasonal dips and peaks.
3. **Product Performance Analysis:** A ranked bar chart highlighting top-selling products (e.g., Paseo) to streamline inventory focus.
4. **Interactive Geographical Filter:** A dynamic Slicer for countries allowing stakeholders to drill down into specific regional performance with a single click.
